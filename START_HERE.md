# Enterprise Data Platform — start here

A Spark and Delta data platform for integrating operational sources, publishing trustworthy analytics, and monitoring pipeline health across industries.

This is an implemented portfolio project with two synthetic local examples. Start with [README.md](README.md) for commands and [docs/STATUS.md](docs/STATUS.md) for checks, evidence, and known limits. `make demo` runs the construction reference example; `make saas-demo` runs usage-to-invoice replay, correction, and recovery. [docs/PLATFORM_CONTRACT.md](docs/PLATFORM_CONTRACT.md) explains the shared behavior and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) shows the flow.

Databricks deployment definitions are prepared but workspace execution has not been verified. Authenticate locally through the supported CLI when a workspace is available; never put tokens in chat or committed files.
